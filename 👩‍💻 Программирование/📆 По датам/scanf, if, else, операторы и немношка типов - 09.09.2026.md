# Switch Case

```C
switch (выражение) {
    case константа1:
        // код, если выражение == константа1
        break;
    case константа2:
        // код, если выражение == константа2
        break;
    default:
        // код, если нет совпадений
}
```
### Главные правила
* **Тип данных:** Выражение в `switch` и значения в `case` должны быть целыми числами (`int`, `char`) или перечислениями (`enum`). Нельзя использовать строки или числа с плавающей точкой.
* **Константы:** Значения после `case` должны быть константными выражениями, известными на этапе компиляции.
* **Оператор `break`:** Нужен, чтобы выйти из `switch`. Если его не написать, программа продолжит выполнять код в следующих `case` (это называется *fallthrough*).
* **Ветка `default`:** Выполняется, если ни один `case` не подошел (она необязательна).
