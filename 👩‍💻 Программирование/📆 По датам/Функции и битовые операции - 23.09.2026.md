# Функции
**Функция** - это именованный блок кода для решения задачи, который можно повторно использовать
### Структура функций
```C
returnType functionName(arguments){
	//body
	return (value):
}
```
- `returnType`
	- `int` - вернёт целое число
	- `float/double` - вернёт вещественное
	- `void` - ничего не вернёт
- `functionName` - Имя функции
- `arguments` - это входные данные, могут быть пустыми
- `//body` **(тело функции)** - блок кода
	-  `return` - вернуть Значение, которое функция выдаст как результат

### Пример с суммой
```C
#include <stdio.h>
int sum(int a, int b){
	return a + b;
}

int main(void){
	int result = sum(222,666);
	printf("sum = %d", result);
	return 0;
}
```

### Пример **мяу мяу мяу**
```C
#include <stdio.h>
void meow(int n){
    for (int i = 0; i < n; i++){
        printf("%d meow\n",i+1);
    }
    return;
}
int main(void){
    meow(25);
    return 0;
}
```

### Голова функции
- **Объявление (declaration) функции** - сообщаем компилятору кратко какое имя у функции и какие типы данных
```C
void woof(int,n);
```
- **Определение(defenition) функции** - определяем что делает функция...
```C
void woof(int n){
	printf("woof %d раз", n);
	return;
}
```
>[!error] Важно!!!
>Чтобы прописать определение функции после главной функции стоит её объявить перед её вызовом.
>Иначе компилятор присвоит ей значение int по дефолту

### Пример с тернальным оператором и максимальным значением
```C
#include <stdio.h>
float max(float a, float b){
    return(a > b ? a : b);
}

int main(void){
    printf("Больше: %f", max(12.43242,34.543657));
    return 0;
}
```

# Битовые операции
- Позволяют работать с отдельными битами
- Работают быстрее некоторых арифметических операций
### printf bin
```C
char dec = 123;
char hex = 0x7b;
char oct = 0173;
char bin 0b1111011;

printf("%d == %d == %d == %d",dec,hex,oct,bin)
printf("%d == %x == %o == ?", dec, hex, oct)
```
Префиксы для разных систем счисления:
`%d`- десятичная
`%x`- шестнадцатеричная
`%o` - восьмеричная
А двоичной нету ))

### Bitwise Operators
& - AND (И)
| - OR (ИЛИ)
`>>,<<` - Shift (Cдвиг)
~ - NOT (Отрицание)
^ - XOR (Искл. ИЛИ)

### Умножение на 2 через битовые операции
a = 3 = 00000011
a << 4 = 00110000 = 3 * 2^4 
### Деление на 2 через битовые операции
a = 17 = 00010001
a >> 1 = 00001000 = 17/2 = 8
### Extract byte
```C
unsigned int a = 0x00C0FFEE;
unsigned char c;
c = (a&0x000000FF); // то же что и (a&0xFF)
printf("first byte of a = %x\n",c); // c == 0xEE

c = ((a >> 8) & 0x000000FF);
printf("second byte of a = %x\n", c); // c == 0xFF
```
### **Extract bit - будет на лабе**
(x>>i) &  i
где
- x - число
- i - битов дл
