```C
}
```

# Stack vs Heap
- **Stack** (стек) - это быстрая и упорядоченная область памяти, работающая по пштципу **LIFO** (Last In First Out).
	- Это стол, на котором лежит стопка книг, для доступа к нужной книге сначала достанем все книги сверху. Если книг положить очень много на стек - то они свалятся со стола, называется это stack overflow, такое можно сделать создав массив больше размера стека, либо сделать бесконечную рекурсию...
- **Heap** (куча) - это больщая и гипкая область памяти, где можно выделять блоки произвольного размера вручную. Управление памятью лежит на программистею
	- **Как гараж бати**, места много, но всё валяется хрен знает где
# Модель памяти языка Си
1. **Text** - код программы, здесь все наши функции с кодом
2. **Data** - данные, здесь хранятся все переменныеявно проинициализированные чем-либо кроме 0
3. **BSS** - все глобальные переменные, что инициализированны 0 или неинициализированны ничем
4. **Heap** - секция кучи, вмя динамически выделенная память через malloc/calloc/realloc
5. **Stack** - секция стека, все локальные переменные, вызовы функций (при вызове функций создаётся кадр функции для возможности вернуться в вызываемое место)
# Virtual and Physical memory
Виртуальная память как и физическая разбиваются на блоки фиксированного размера - **странницы**. Когда программа пытается получить доступ к своей виртуальной памяти, **ОС и процессор и чип MMU переводят вирткальный в физический адрес**. Когда процу говорят прочитай значение праого числа по некоторому адресу. то он лезет в **MMU** для перевода этого адреса в физический.
А ещё виртуальная память позволяет создавать и использовать **swap** - файл подкачки
# Recursion
**Рекурсия** - это поведение функции, при котором она вызывает сама себя
```C
int factorial(int N){
	if (N < 1) return;
	return N * factorial(N-1);
}
int n = factorial(5);
```
# Аргументы у main()
- **argc** - целое число, количество аргументов, всегда как минимум будет один нулевой аргумент - название исполняемого файла
- **argv** - массив строк, в ней будут аргументы в виде строк, индексы строк от 0 до argc - 1 включительно

# Callback
**Callback** - функция обратного вызова в программировании - передача исполняемого кода в качестве одного из параметров другому коду.

Простыми словами это функция, которая передаётся в другую функцию как аргумент и вызывается позже
# API
**API** - программный интерфейс приложения, описывает протокол взаимодействия между программами. Представляет собой набор классов, функций, структур или констант

# ABI (Application Binary Interface)
**ABI** - двоичный интерфейс приложения, описывает набор соглашений для доступа к операционной системе и низкоуровневым сервисам.
