# **Матрица** - комната со шкафами
Массивы бывают не только одномерными, **матрица** - это двумерный массив, потому что он выглядит как таблица со строками и столбцами. Индексы по прежнему начинаются с 0!

### Объявление и инициализация
Нужны две пары квадратных скобок:
```C
#define ROWS 3
#define COLS 4

int m[ROWS][COLS]; // 3 строки, 4 столбца
```
Первый индекс - **строка** (row), второй - **столбец** (column). Доступ: `m[i][j]`, где `i` - номер строки, `j` - номер столбца.

Разные варианты: 
```C
// Полная - по строкам, как в тетради
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// То же самое, но в одну строку (браузер читает так же)
int b[2][3] = {1, 2, 3, 4, 5, 6};

// Недостающие элементы станут нулями; строки можно "недозаполнять"
int c[3][3] = {
    {1, 2},        // 1 2 0
    {4},           // 4 0 0
    {7, 8, 9}      // 7 8 9
};

// Всё нулями
int zeros[3][3] = {0};

// Designated initializers (С99)
int d[3][3] = {[0][0] = 1, [2][2] = 1}; // единичная матрица 3×3

// Размер по первой размерности можно не указывать
int grid[][3] = {{1, 2, 3}, {4, 5, 6}}; // размер посчитается сам: grid[2][3]
```
>[!warning] Важно
>Нужно указывать **обе** размерности: и количество строк, и количество столбцов. Компилятору это нужно, чтобы выделить память

### Как матрца лежит в памяти
В памяти матрица 3×3 лежит как **три подряд идущих одномерных массива** по 3 элемента (по строкам)
```C
int m[3][3] = {
    {1, 2, 3},   // в памяти первыми: 1 2 3
    {4, 5, 6},   // потом: 4 5 6
    {7, 8, 9}    // и последними: 7 8 9
};
// в памяти: 1 2 3 4 5 6 7 8 9
```
Такой порядок называется **row-major** (по строкам). Именно поэтому при обходе матрицы внешний цикл ставят по строкам: так мы идём по памяти последовательно, и процессор кэширует данные оптимально

### Диагонали
У квадратной матрицы есть две диагонали **главная** и **побочная**

**Главная** диагональ, когда номер строки равен номуру столбца, т.е `i == j`:
```C
for (int i = 0; i < N; i++) {
    printf("%d ", matrix[i][i]); // [0][0], [1][1], [2][2], ...
}
printf("\n");
```

**Побочная** диагональ, когда `i + j == N`
```C
for (int i = 0; i < N; i++) {
    printf("%d ", matrix[i][N - 1 - i]); // [0][N-1], [1][N-2], ...
}
printf("\n");
```
#### Примеры
```C
// Сумма элементов главной диагонали
int sum = 0;
for (int i = 0; i < N; i++) {
    sum += m[i][i];
}

// Проверка: симметрична ли матрица относительно главной диагонали
int is_symmetric = 1;
for (int i = 0; i < N; i++) {
    for (int j = 0; j < N; j++) {
        if (m[i][j] != m[j][i]) {
            is_symmetric = 0;
        }
    }
}
```
**Через сравнение `if (i == j)` внутри двойного цикла тоже можно** - но это медленнее: мы пробегаем всю матрицу ради `N` элементов. Одним циклом короче и быстрее.
### Транспонирование
**Транспонирование** - отражение матрицы относительно главной диагонали

Для **квадратной** можно:
```C
// Квадратная матрица N × N
for (int i = 0; i < N; i++) {
    for (int j = i + 1; j < N; j++) { // j начинается с i+1 !!
        int tmp = m[i][j];
        m[i][j] = m[j][i];
        m[j][i] = tmp;
    }
}
```
Для **неквадратной** атрицы `ROWS` × `COLS` транспонирование на месте невозможно (получится `COLS` × `ROWS`, размер другой), поэтому результат пишут в отдельный массив: 
```C
int t[COLS][ROWS];
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        t[j][i] = m[i][j]; // строки и столбцы поменялись местами
    }
}
```
### Матрицы в реальности и 3D
**Матрицы** - рабочая лошадка очень многих областей:

- **Графика и игры.** Поворот, масштаб, сдвиг 3D-модели - это умножение на матрицу 4×4. Ваш персонаж двигается в игре именно так.
- **Картинки.** Чёрно-белая картинка - матрица яркостей, цветная - три матрицы (R, G, B).
- **Нейросети и ML.** В основе "нейронок" - умножение матриц на матрицы. Чем быстрее умножаем, тем быстрее обучается модель.
- **Таблицы данных.** Excel, база данных, журнал оценок - всё это таблицы, то есть матрицы.
```C
#define X 2
#define Y 3
#define Z 4

int cube[X][Y][Z]; // 2 × 3 × 4
```
>[!error] Про размерности
>На практике больше 2-3 размерностей берут редко: чем больше мерностей, тем сложнее код и тем хуже он ложится в кэш. Если захотелось 5D-массив - скорее всего, структуру данных стоит пересмотреть

### Свёртка: как размывают матрицу
**Картинка** - это матрица яркостей. Размытие, повышение резкости, поиск границ - всё это **свёртка**: новое значение пикселя считается как взвешенная сумма его соседей.

Проще всего показать на размытии 3×3: новый пиксель - среднее арифметическое девяти соседей
```C
#define H 4
#define W 4

void blur(int h, int w, int src[h][w], int dst[h][w]) {
    for (int i = 0; i < h; i++) {
        for (int j = 0; j < w; j++) {
            int sum = 0;
            int count = 0;

            for (int di = -1; di <= 1; di++) {
                for (int dj = -1; dj <= 1; dj++) {
                    int ni = i + di; // соседняя строка
                    int nj = j + dj; // соседний столбец
                    // проверка границ: за пределами матрицы не читаем!
                    if (ni >= 0 && ni < h && nj >= 0 && nj < w) {
                        sum += src[ni][nj];
                        count++;
                    }
                }
            }
            dst[i][j] = sum / count;
        }
    }
}
```
Тут важны две вещи. Первая - **проверка границ**: у краевых пикселей нет девяти соседей, и чтение `src[i - 1][j]` без проверки вылетит за массив. Вторая - результат пишем в **отдельную** матрицу: если писать сразу в `src`, то соседи, которые ещё не обработаны, уже окажутся размытыми и картинка "поплывёт" при движении слева-вправо-вниз.

# **Строка** - массив символов
В Си нет отдельного примитивного типа `string`. **Строка в Си** - это массив `char`, в конце которого стоит особый символ - нуль-терминатор `'\0'`
```C
char s[] = "Hi!";
printf("%s\n", s); // Hi!
```
Пустые `[]` - компилятор сам посчитает размер. `%s` - формат для строки в `printf`.

Как ещё объявить:
```C
char a[] = "Hi!";                 // размер 4 (с '\0')
char b[10] = "Hi!";               // 10 байт: H i ! \0 \0 \0 \0 \0 \0 \0
char c[4] = {'H', 'i', '!', '\0'}; // то же, что a, но руками
```

## Ввдод и вывод сток
Вывод. `printf("%s", s)`, `puts(s)` (добавляет `\n`), `putchar(c)` (один символ).
```C
char s[] = "Hi!";
printf("%s\n", s);
puts(s);             // то же самое, но перевод строки добавит сам
```
### **Ввод**- 2 Основных способа
1. `scanf` со спецификатором `%s` - читает до первого пробела/перевода строки. `&` **не нужен**, потому что имя массива уже само по себе передаёт адрес первого элемента:
```C
char name[20];
printf("Enter name: ");
scanf("%s", name);
printf("Your name is %s\n", name);
```
2. `fgets()` - современный и безопасный вариант. Читает строку **вместе с пробелами** и никогда не пишет больше, чем поместится:
```C
char name[20];
printf("Enter name: ");
fgets(name, sizeof(name), stdin); // stdin - стандартный поток ввода (клавиатура)
printf("My name is %s\n", name);
```
Нюанс `fgets`: он оставляет `\n` в конце, если строка поместилась. Обычно перевод строки срезают:

```c
fgets(name, sizeof(name), stdin);

size_t len = strlen(name);
if (len > 0 && name[len - 1] == '\n') {
    name[len - 1] = '\0';
}
```
### Функции из string.h и ctype.h
#### string.h
- `strlen(s)` - длина строки без `'\0'`
- `strcpy(dest, src)` - копирование строки
- `strncpy(dest, src, n)` - то же, но не более `n` байт
- `strcmp(a, b)` - сравнение: `0` если равны
- `strncmp(a, b, n)` - сравнение первых `n` символов
- `strcat(dest, src)` - дописать `src` в конец `dest`
- `strncat(dest, src, n)` - то же, но не более `n` символов
- `fgets(s, n, stdin)` - ввод строки
- `puts(s)` - вывод строки плюс `\n`
##### Значения `strcmp`:
- `0` - строки **равны**;
- `> 0` - первый различающийся символ в `a` больше, чем в `b`;
- `< 0` - меньше.
Пример: 
```C
char login[128] = "ivan";             // логин пользователя
printf("Длина логина: %zu\n", strlen(login)); // 4

strcpy(login, "student");             // логин сменили
printf("Новый логин: %s\n", login);   // student

char email[128];                      // собираем email из логина и домена
strncpy(email, login, sizeof(email));
email[sizeof(email) - 1] = '\0';      // strncpy может не закрыть строку
strncat(email, "@sibguti.ru", sizeof(email) - strlen(email) - 1);
printf("Email: %s\n", email);         // student@sibguti.ru

if (strcmp(saved, entered) == 0) {    // проверка пароля при входе
    puts("Пароль верный");
}
```

# **Сортировка** - алгоритм упорядовачивания данных в массиве
Алгоритмов сортировок много, и на больших массивах работают они очень по-разному:

- Bubble Sort - **пузырьковая**
- Insertion Sort - **вставками**
- Selection Sort - **выбором**
- Counting Sort - **подсчётом**
- Radix Sort - **поразрядная**
- Merge Sort - **слиянием**
- Quick Sort - **быстрая**
### Bubble Sort - **пузырьковая**
Самая простая для понимания. Много раз проходим по массиву и сравниваем соседние элем
енты: если текущий больше следующего - меняем местами. Большие числа "всплывают" к концу, как пузырьки.
```
ДЛЯ i от 0 до n-1:
    ДЛЯ j от 0 до n-i-1:
        ЕСЛИ arr[j] > arr[j+1]:
            поменять местами arr[j] и arr[j+1]
```
![](https://camo.githubusercontent.com/0917e708dbadb36e5ff88f52628e2d3800ab20c68cdce6dedf70dad5702884ab/68747470733a2f2f75706c6f61642e77696b696d656469612e6f72672f77696b6970656469612f636f6d6d6f6e732f632f63382f427562626c652d736f72742d6578616d706c652d33303070782e676966)

```C
void bubble_sort(int size, int arr[size]) {
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            if (arr[j] > arr[j + 1]) { // текущий больше следующего, меняем местами
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
        }
    }
}

// ...
#define N 6
int prices[N] = {1290, 199, 450, 89, 640, 79}; // цены в каталоге
bubble_sort(N, prices); // отсортировано по возрастанию цены
```
Сортировку можно чуть ускорить: если за очередной проход не было ни одного swap, массив уже отсортирован - можно выйти:

```c
int swapped = 1;
for (int i = 0; i < size && swapped; i++) {
    swapped = 0;
    for (int j = 0; j < size - i - 1; j++) {
        if (arr[j] > arr[j + 1]) {
            int tmp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = tmp;
            swapped = 1;
        }
    }
}
```

**Важно ещё раз:** массив **можно передать в функцию**, но **вернуть массив из функции нельзя**. Поэтому все сортировки меняют массив прямо на месте.
###  Insertion Sort - **вставками**
![](https://camo.githubusercontent.com/cbe29af132e02572246bd98bcbe38f09f07cfc221f10b763acc6e8cf8849ee5b/68747470733a2f2f75706c6f61642e77696b696d656469612e6f72672f77696b6970656469612f636f6d6d6f6e732f302f30662f496e73657274696f6e2d736f72742d6578616d706c652d33303070782e676966)
Идём слева направо. Каждый новый элемент "вынимаем" и **вставляем** в правильное место среди уже отсортированной левой части. Отсортированная часть растёт с каждым шагом. Первый элемент считаем отсортированным - поэтому внешний цикл начинается с индекса 1.
```C
void insertion_sort(int size, int arr[size]) {
    for (int i = 1; i < size; i++) {
        int key = arr[i];        // "вынимаем" текущий
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j]; // сдвигаем большие вправо
            j--;
        }
        arr[j + 1] = key;        // вставляем на место
    }
}
```
### Selection Sort - **выбором**

Находим минимальный элемент в ещё не отсортированной части и ставим его в начало этой части. Повторяем. Здесь swap происходит максимум `n-1` раз - это плюс, когда обмен элементов "дорогой".
![](https://camo.githubusercontent.com/295637366cbe0cfc702fe4edefff1032d3aff8d7b2b1222c84cd64969c84473c/68747470733a2f2f75706c6f61642e77696b696d656469612e6f72672f77696b6970656469612f636f6d6d6f6e732f392f39342f53656c656374696f6e2d536f72742d416e696d6174696f6e2e676966)
```c
void selection_sort(int size, int arr[size]) {
    for (int i = 0; i < size - 1; i++) {
        int min_index = i;
        for (int j = i + 1; j < size; j++) {
            if (arr[j] < arr[min_index]) {
                min_index = j;
            }
        }
        int tmp = arr[i];
        arr[i] = arr[min_index];
        arr[min_index] = tmp;
    }
}
```
### Counting Sort - **подсчётом** и Radix Sort - **поразрядная**
Эти сортировки одни из самых быстрых, и им **не нужно сравнивать** элементы между собой.

##### **Counting Sort** 
работает, когда значения лежат в небольшом известном диапазоне. Идея: заводим массив-счётчик `count` размером с диапазон и считаем, сколько раз встречается каждое значение:

```c
count[arr[i]]++;  // arr - сортируемый массив, count - счётчик
```

Потом проходим по `count` по порядку и печатаем значения столько раз, сколько насчитали - массив выходит отсортированным. Два раза встретилась единица? Выведем два раза. Картинка:

##### **Radix Sort**
сортирует по разрядам: сначала по младшему, потом по следующему и так далее. Для десятичной системы:

То же самое работает и в двоичной системе.

**Плюсы**: быстрые и без сравнений. Минус: применимы не ко всем данным (нужны целые числа в известном диапазоне).
