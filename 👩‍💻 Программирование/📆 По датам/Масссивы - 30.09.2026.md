# Bitwise Ops (Повторение)
Пример с системами счисления
```C
#include <stdio.h>

void print_bin(int dec) {
    // в обратном порядке for (int i = 0; i < sizeof(dec)*8 ; i++)
    for (int i = sizeof(dec)*8 - 1; i >= 0 ; i--) {
        printf("%d", (dec >> i) & 1);
    }
    printf("\n");
}

int main(void) {

    char dec = 123;
    char hex = 0x7b; // or 0x7B
    char oct = 0173;
    char bin = 0b01111011;

    printf("%d == %d == %d == %d\n", dec, hex, oct, bin);
    printf("%d == 0x%x == 0%o == 0b", dec, hex, oct);


    print_bin(bin);

}
```

# Массивы
**Массивы** используются для хранения нескольких значений в одной переменной вместо объявления отдельных переменных для каждого значения.

Если переменная это коробка, то массив - это шкаф с коробками.

Массивы в ЯП (В том числе C) умеют хранить **только значения одного типа данных**.

```C
int scores[3] = {77, 43, 100}
```
Массивы C/C++, Python, Java, Go и тд.. индексируются с 0. 
Исключения, где массивы начинаются с 1: MATLAB, lua, R, Julia...

### Пример
```C
#include <stdio.h>

int main(void){
    int scores[3] = {90, 85, 78};
    printf("Scores: ");
    for (int i = 0; i < 3; i++){
        printf("%d, ", scores[i]);
    }
    printf("\n");
}
```

### Ошибки
**Segmentation fault** - ошибка во время выполнения кода, когда программа попыталась обратиться к памяти, к которой доступ не разрешён.
```C
    int a[5] = {1, 2, 3, 4, 5};
    int b[5] = {5, 4, 3, 2, 1};

    b = a; // Error
    a = b; // Error

    a[2] = -17; //ok
    a[0] = b[4]; //ok

    a[2.5] = 33; // Error: array index must be an integer
    b[4000] = 100; // Error: out of bounds access
    a[-1] = 8; // ok, but undefined behavior
```
>[!error] Главная ошибка
>**C** - позволяет выйти за рамки массива, но из за этого в программе возникают ошибки, поэтому нужно быть внимательнее

### Как узнать размер массива
```C
int m[] = {1,2,3};
int array_size = sizeof(m) / sizeof(m[0]); //12/4 = 3
```
Размер в байтах всего массива / размер 1 элемента

### Переворот массива
```C
#include <stdio.h>

int main(void){
    int a[3] = {1, 2, 3};
    int n = 3;

    for (int i = 0; i < n / 2; i++) {
        int temp = a[i];
        a[i] = a[n - 1 - i];
        a[n - 1 - i] = temp;
    }
    printf("Reversed array: %d %d %d\n", a[0], a[1], a[2]);
    return 0;
}
```
