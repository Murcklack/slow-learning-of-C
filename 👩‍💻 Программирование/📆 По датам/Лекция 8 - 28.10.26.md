# Этапы сборки программы 
## 1. Предпроцессор 
 **Расскрывает диррективы** предпроцессора в начале кода
#### Дирректива #include
Искать в текущем каталоге через `""`
```C
#include "my_header.h"
```
Искать в  стандартных путях `< >`
```C
#include <stdio.h>
```
#### define - дирректива предназначенная для макро определений
Позволяют оптимизировать написание кода
**Все макро определения пишут большими буквами** - правло хорошего тона
Используют:
- для определения констант (#define 5)
- для определения макросов 
>[!danger] Это не переменная
>Её нельзя переопределить сразу.
>Можно удалить через `#undef` и снова объявить через `#define`
##### Предопределённые костанты
- `__LINE__` - номер строки
- `__FILE__` - имя файла
- `__FUNCTION__` - имя функции
- `__DATE__` - дата компиляции
- `__TIME_` - время компиляции
##### Условная компиляция
```C
#if B == 5
#else
#endif
gcc src/cond.c -DB=5 // Во время компиляции можно -D

#ifdef DEBUG
#else
#endif
gcc src/cond.c -DEBUG=1
```
