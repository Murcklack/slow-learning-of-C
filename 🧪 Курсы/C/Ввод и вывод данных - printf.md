# Основной синтаксис
`printf("формат-строка", аргумент1, аргумент2, ...);`
Аргументы могут быть переменными, выражениями и просто значениями.

## **Формат-строка** состоит из:

- обычных символов (выводятся как есть)
- escape-последовательностей (начинаются с `\`)
- спецификаторов формата (начинаются с `%`)

## Основные **escape-последовательности** (воспринимается как единый символ):

- `\n` - новая строка
- `\t` - табуляция (обычно 8 пробелов)
- `\"` - двойная кавычка
- `\\` - обратный слеш
- `\'` - одинарная кавычка

## Базовые **спецификаторы формата**:

- `%d` - целые числа (`int`)
- `%f` - вещественные числа (`float/double`)
- `%c` - символы (`char`)
# Модификаторы формата:

##  Порядок упоминания:

`%[флаги][ширина][.точность]буква_спецификатора`

## **Флаги:**

- `-`  - выравнивание по левому краю (по умолчанию идёт выравнивание по правому краю)
- `+`  - всегда показывать знак числа

## **Ширина:**

- Число перед буквой: `%5d` - минимальная ширина поля для вывода
- Если число не помещается - поле расширяется;

## **Точность:**

- Для `%f`: количество знаков после точки (`%.2f` = 2 знака)
- Для `%d`: минимальное число цифр (дополняется нулями слева)

## **Важные правила:**

- Количество спецификаторов должно совпадать с количеством аргументов
- Тип спецификатора должен соответствовать типу аргумента
- Спецификаторы заменяются аргументами по порядку слева направо

## **Примеры:**

```c
printf("|%8.3f|", 3.1415926);  // |   3.142|
printf("|%-8.3f|", 3.1415926); // |3.142   |
printf("|%+8.3f|", 3.1415926); // |  +3.142|
printf("|%.4f|", 3.1415926);   // |3.1416|
printf("|%.5d|", 123); // |00123|
```
